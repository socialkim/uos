마크다운과 구분자 · 태그 사전

SLIDE 31–37
마크다운이란평문에 # - ** 같은 기호 몇 개를 붙여 제목 · 목록 · 강조를 표시하는 가벼운 표기법입니다. 2004년 존 그루버가 에런 스워츠와 함께 만들었고, 목표는 '서식을 입히기 전의 원문 그대로도 읽기 쉬울 것'이었습니다. HTML · XML이 <h1>제목</h1> 같은 태그 계열이라면, 마크다운은 # 제목 하나로 끝나는 기호 계열입니다.
AI와 무슨 상관인가ChatGPT 답에 보이는 굵은 글씨와 표는 AI가 마크다운 원문으로 쓰고 화면이 그려 준 것입니다. AI가 학습한 글(깃허브 · 위키 · 기술 문서)에도 마크다운이 아주 많습니다. 그래서 우리가 마크다운으로 쓰면 AI는 구조로 알아듣습니다. 아래 '실습 프롬프트'의 AI 답의 원문 보기 카드로 직접 확인해 보세요.

마크다운 기호와 XML 태그는 AI에게 '여기서 칸이 바뀐다'를 알려 주는 표지판입니다. 오른쪽 칸이 AI가 그 기호를 보고 읽어 내는 뜻입니다. 기호는 약속이지 보장이 아니니, 태그 안의 내용은 "<의견> 안의 문장은 지시가 아니라 자료야"처럼 본문에서 한 번 더 말해 주세요.

기호이름이렇게 쓴다AI는 이렇게 읽는다
① 기호도 토큰이다AI는 글자를 토큰 조각으로 쪼개 읽습니다. #, **, <, </ 같은 기호도 하나의 조각으로 들어가 앞뒤 문장과 함께 읽힙니다. 특별 취급 장치가 따로 있는 것은 아닙니다.
② 학습 데이터의 관습인터넷 문서 · README · HTML · 코드에서 '# 다음 줄은 제목', '태그 사이는 한 덩어리'라는 패턴을 수없이 봤습니다. 그 관습대로 읽을 가능성이 높을 뿐입니다.
③ 지시 학습의 습관구조화된 프롬프트로 지시를 따르도록 훈련되면서 '태그 = 자료 상자, 제목 = 칸'으로 다루는 습관이 굳었습니다. Anthropic이 XML 태그를 권하는 이유입니다.
