# 에이전트 설계 캔버스 (8칸)

> 9주차 실습 B·D용. 돌리기 전에 한 장으로 채운다. 빈칸 표는 내 주제용, 아래 표는 공통 과제 예시.

## 내 주제

| 칸 | 묻는 것 | 내 답 |
|---|---|---|
| ① 목표 | 끝나면 무엇이 손에 있나(한 문장) | |
| ② 입력 자료 | 내가 줄 것 | |
| ③ 도구 | 손발(통계 MCP · 법령 MCP · 웹 검색 · 파일 읽기 …) | |
| ④ 노하우(스킬) | 일하는 법(SKILL.md + 참고 파일) | |
| ⑤ 단계 | 순서 | |
| ⑥ 사람 확인 지점 | 어디서 멈추고 사람이 보나 | |
| ⑦ 출력 | 결과 모양 | |
| ⑧ 실패할 때 | 도구가 없거나 틀리면 | |

## 공통 과제 예시 — 「시립대 앞 첫 자취방 계약 — 문제 정의 브리핑」(가상 연습)

| 칸 | 예시 |
|---|---|
| ① 목표 | 첫 자취방 계약의 어려움을 근거와 함께 정의한 한 장 브리핑 |
| ② 입력 자료 | 가상 설문 30명 CSV, 가상 인터뷰 3명 TXT |
| ③ 도구 | 통계 MCP, 법령 MCP, 웹 검색, 파일 읽기 |
| ④ 노하우(스킬) | problem-brief(SKILL.md + 참고 파일 3개) |
| ⑤ 단계 | 목표 확인 → 계획 → 첨부 자료 → 통계 → 법령 → 기존 해법 → 브리핑 → 레드팀 → 출처 |
| ⑥ 사람 확인 지점 | 목표 확인 답, 출처 클릭, 조문 대조, 최종 채택 |
| ⑦ 출력 | 한 장 브리핑(근거 표 · 레드팀 메모 · 사람이 확인할 것) |
| ⑧ 실패할 때 | 웹으로 대체 표시, 조회 실패 표시, 숫자 지어내지 않기 |

## 돌리기 전 마지막 점검
- [ ] ①이 한 문장인가
- [ ] ③은 필요한 것만인가
- [ ] ⑥이 최소 두 곳 있는가
- [ ] ⑧에 "지어내지 않는다"가 있는가
